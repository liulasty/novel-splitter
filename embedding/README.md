## embedding

`embedding` 模块是本系统构建智能检索能力的核心基建，其核心职责是提供高效的文本向量化（Embedding）处理能力，并支持与向量数据库的交互管理。在 RAG（检索增强生成）架构中，该模块是将自然语言转化为机器可理解的高维数学表示的关键桥梁。其主要功能分为两大部分：一是集成了本地化的嵌入模型引擎，能够快速将拆分后的文本片段转换为高维向量；二是提供了标准化的向量存储（VectorStore）接口，支持数据的内存级管理以及与专业的 Chroma 向量数据库进行对接。在外部依赖上，该模块深度整合了 `onnxruntime` 以支持本地 ONNX 格式模型的推理加速，同时引入了与第三方 Chroma 数据库通信的客户端驱动库，并依赖 `domain` 模块来获取需要处理的实体数据。这种设计不仅保障了数据隐私（支持本地向量化），还提供了强大的海量向量存储与高维相似度检索能力。

**典型使用场景与入口类说明：**
* 核心服务类为 `OnnxEmbeddingService`（负责文本到向量的转换推理）以及 `ChromaVectorStore`（负责向量的存储与查询）。
* 在知识库构建阶段，系统调用此模块将校验合格的场景片段转化为向量并存入 Chroma 数据库。
* 在用户提问检索阶段，系统再次调用此模块将用户查询（Query）向量化，并在向量库中执行 KNN（K近邻）相似度搜索以召回相关上下文。
