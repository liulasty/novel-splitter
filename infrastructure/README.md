## infrastructure

`infrastructure` 模块是本系统的基础设施层，主要致力于提供与具体业务逻辑无关的通用技术支撑和基础工具类。其核心职责是将各个业务模块在日常开发中频繁使用的底层技术细节进行统一封装与抽象，从而大幅减少重复代码的编写，提升整体开发效率与代码质量。该模块的主要功能包括提供高效的本地文件读写及目录操作支持（通过 `FileUtils` 等类实现），以及提供标准化的 JSON 数据序列化与反序列化处理能力（通过 `JsonUtils` 等类实现）。在对外依赖方面，该模块引入了 `jackson-databind` 以实现强大的 JSON 解析功能，同时依赖了 `commons-io` 和 `commons-lang3` 等 Apache 开源组件库来增强文件处理和字符串操作的底层能力。通过这种职责分离的设计，系统中的核心业务模块得以将重心完全放在业务规则的实现上，而无需关心复杂的底层 I/O 与数据转换细节，极大增强了系统的健壮性和可维护性。

**典型使用场景与入口类说明：**
* 各业务模块（如 `repository`、`novelDownloader` 等）在需要进行本地文件读写、创建存储目录等操作时，直接调用本模块提供的文件处理工具类。
* 系统内部各模块在进行数据持久化、网络请求响应解析或跨模块数据传递时，广泛调用 `JsonUtils.fromJson()` 或 `toJson()` 方法进行数据格式转换。
* 作为通用技术底座，它被设计为无状态且高度可复用的组件库，任何需要基础支撑的模块均可按需引入。
