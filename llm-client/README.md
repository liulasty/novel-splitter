## llm-client

`llm-client` 模块是本系统与外部人工智能大脑交互的“网关”，核心职责是统一封装并标准化对各大主流大语言模型（LLM）的 API 调用。由于不同的模型厂商通常提供各异的接口协议，该模块通过抽象出统一的调用接口，屏蔽了底层的网络通信差异。其主要功能包括：支持 Google Gemini、DeepSeek、Coze 以及本地化的 Ollama 等多种大模型引擎；处理复杂的网络请求构建与响应解析；提供模型参数（如最大 Token 数、温度值等）的动态配置；以及集成了基于 `spring-retry` 的自动重试和超时恢复机制，极大增强了外部调用的稳定性。在对外依赖方面，它引入了各类模型厂商官方或第三方的 SDK（如 OpenAI 兼容接口），并依赖 Spring Boot 的 AOP 与重试组件来实现高可用设计。这种高度抽象的架构赋予了系统“热插拔”切换不同 AI 模型的能力。

**典型使用场景与入口类说明：**
* 核心统一接口为 `LlmClient`，所有对大模型的业务调用均通过此接口发起。
* 包含了诸如 `GeminiLlmClient`、`DeepSeekLlmClient` 等多种具体实现类，系统可根据配置动态注入所需的 Bean。
* 在智能问答的最终环节，系统通过本模块将 `context-assembler` 组装好的 Prompt 发送至目标大模型，并接收、解析其生成的最终回答。
