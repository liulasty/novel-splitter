## validation

`validation` 模块是本系统数据质量的“守门员”，其核心职责是对经过引擎拆分后生成的场景片段进行严格的质量校验，确保最终产出的数据符合预设的标准。在 RAG（检索增强生成）架构中，检索到的上下文质量直接决定了 LLM 回答的准确性，因此该模块的存在至关重要。其主要功能是实现多维度的校验逻辑，目前重点包括对场景文本长度的检查（如剔除过短的无意义片段或过长的超限片段），以及潜在的语义连贯性分析。通过提供统一的校验规则接口，系统可以自动标记或过滤掉不合格的拆分结果，从而为后续的向量化和检索环节提供高纯度的数据源。在外部依赖方面，该模块主要依赖 `domain` 模块中定义的 `Scene` 等实体模型，以获取需要校验的结构化数据。它的轻量级设计使其能够无缝嵌入到整个处理流水线中，发挥质量控制的关键作用。

**典型使用场景与入口类说明：**
* 核心接口为 `SceneValidator`，它定义了校验场景片段质量的标准契约。
* 典型的具体实现类如 `LengthValidator`，用于执行基于字数限制的具体规则校验。
* 该模块主要在 `pipeline` 模块的 `ValidationStage`（校验阶段）中被集中调用，拦截并处理不符合规范的脏数据。
